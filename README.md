# J.P. Morgan Legal Document Classification

> **Introduction to Data Analytics**

## 📌 Project Overview

This project focuses on the classification of legal documents inspired by **J.P. Morgan's COIN (Contract Intelligence)** system.

The project explores how data analytics and machine learning can be applied to automate the classification of legal document clauses, reducing manual effort and improving the efficiency of document review.

## 🎯 Business Objective

The primary objective is to:

**Automate the classification of various legal documents.**

The problem is analyzed using the **CRISP-DM (Cross-Industry Standard Process for Data Mining)** methodology.

## 🏦 Background

J.P. Morgan developed COIN (Contract Intelligence) to automate the review of certain commercial loan agreements.

The system was designed to identify patterns in contracts and categorize repeated clauses into different attributes. This approach demonstrates how automation can significantly reduce the time and effort required for manual legal-document review.

## 🔍 Problem Statement

Legal documents contain large amounts of information and repeated contractual clauses. Manually reviewing and categorizing these clauses can be time-consuming.

This project addresses the problem of automatically classifying legal clauses using a data-driven approach.

## 🔄 CRISP-DM Methodology

The project follows the major stages of the CRISP-DM framework:

### 1. Business Understanding

Understand the business problem and define the objective of automating legal-document classification.

### 2. Data Understanding

Explore the available legal-clause data and understand its structure, attributes and patterns.

### 3. Data Preparation

Prepare the data for analysis and machine-learning classification.

### 4. Modeling

Develop a classification approach to categorize legal clauses.

### 5. Evaluation

Evaluate the classification process and determine whether the solution addresses the business objective.

### 6. Deployment

Consider how the classification solution could be applied in a practical legal-document review environment.
